# PW 震动覆盖与本轮测试

AC7 参考配置列出 **46 个效果 ID**，其中 BombFire（ID 8）在参考消费端被排除。那是游戏提供的分类表，不是 46 种载波频率，也不能等同于每一项都在现场验证。

PW 目前接入 **6 组来源**：3 条原生生产路径，加上机炮、受损、飞机销毁。受损再分轻伤/重创，形成下表 **7 个测试项目**。两条动态原生路径进入四马达混合后不携带效果 ID，因此不是 7 个可独立识别和调节的原生类别，更不能宣称覆盖了 AC7 的 46 项。

| 测试项目 | 触发来源与手感 | 当前证据 |
|---|---|---|
| 导弹发射 | 游戏 MissileLaunch 原生包络；由最终通道决定 60/70 ms 周期 | 原生请求、包络和实机震动已确认 |
| 云层/气流 | 原生全马达动态通路，保留游戏包络 | 用户已认可穿云体验；混合通道不提供云层事件 ID，不能继续细分 |
| 推力相关震动 | 原生小马达动态通路，不额外合成加力效果 | Start/Update 与推力上升有时间关联；独立有效输出及完整触发条件待测，不算已验收 |
| 机炮出弹 | 本机 Cannon_GP、Cannon_Gau、CANNON_BASE 弹体完成生成；28 ms 周期、80 ms 衰减 | 生成/完成调用与类名已静态核实，隔离调用通过；新实机触发待测 |
| 轻伤 | 存活时单次生命值下降不足前值 20%；35 ms 周期、200 ms 衰减 | 软件检查通过，空中受击尚未实测 |
| 重创 | 存活时单次生命值下降至少前值 20%；80 ms 周期，保持峰值 200 ms 后用 600 ms 衰减，总长 800 ms | 按用户决定与坠毁同步包络；峰值仍随损血比例计算，待测 |
| 坠毁/被击毁 | 本机 g_IsDestroyed 或生命值耗尽；80 ms 周期，前 200 ms 满幅保持，再用 600 ms 衰减，总长 800 ms | 上轮两次已输出满幅约 328/344 ms，用户反馈太轻短；本轮加长包络待测 |

损血比例控制受损强度；全局增益仍为 1.5，幅度封顶。所有来源按当前最大幅度选择，不相加；新事件没有覆盖或替换原生导弹曲线。

坠海、撞地、被击毁目前统一为“飞机销毁”，不凭高度、姿态或速度突变猜测原因。轻伤/重创也不冒充机炮/导弹两种伤害武器类型。未接入失速、高 G、闪电、起降、空中加油或敌机爆炸等缺少可靠触发证据的分类；推进这些项需要定位真实来源，不能仅复制 AC7 名称造数量。现有导弹与动态输出会自然覆盖经过这些原生生产者的其它行为，但没有身份的来源不另行计数。

## 一次测试即可

本轮按用户决定联合测试杆力与震动。退出旧程序和 PW，打开 Cockpit 并沿用现有 PW Default 预设，从项目根目录运行：

```powershell
.\payload\DCS.exe
```

确认控制台出现 `[tcp] Cockpit client connected`，正常启动 PW。正常飞行先感受杆力，再短点射和连续开炮，预期出弹时震动、停火后约 80 ms 内消退，且杆力继续工作。穿云/导弹可顺便检查；有机会存活受损，再看轻伤/重创。最后任选坠海或撞地，预期约 0.8 秒的明显连续冲击，前 0.2 秒保持强度，随后淡出。暂停、切窗及退出检查两路停止，不要求逐项反复试飞。仅震动模式 `--vibration-only` 仍保留，供定位共存问题时使用。

日志中的 `gun_begin/gun_local_begin/gun_finish/gun_shots/gun_updates` 区分发射来源与输出；桥接打印 `impact=Damage/HeavyDamage/Destroyed`。日志路径在控制台开头打印。暂停、切窗和退出仍停止输出；软件检查不能替代实际触感验收。
