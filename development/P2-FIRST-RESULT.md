## 速度与位移对照

同一 session 内、游戏时间间隔 0.3～2 秒的 99 对样本，计算：

```text
位置差长度 / 游戏时间差 / 相邻前向速度均值
```

比例的最小值/四分位/中位/四分位/最大值约为：

```text
0.9734 / 0.9992 / 1.0001 / 1.0005 / 11.5209
```

大多数片段接近 1，说明内部前向速度与位置单位/游戏时间相符。但有 9 对出现 4.15～11.52 倍异常位移，第一段多发生在游戏时间 70、80、90、100、110、120 秒附近，**怀疑世界原点重定位，尚未证实**。不能把这些位置跳变直接求导，否则会产生危险尖峰。

按标准 UE 长度单位 cm 假设，将前向速度从 cm/s 换算为节：

```text
22824.9199 cm/s / 100 / 0.514444... ≈ 443.68 kt
```

该样本航向归一化为 196.94°，与截图的 444–445 / 197°一致，且截图雷达使用 MI。这是对首张截图的候选解释，不是 HUD 固定使用节的结论。用户已确认单位在设置中可调，后续改为 km/h；不要将这个截图数字直接当成当前 km/h 读数，也不要让显示单位影响内部速度转换。
